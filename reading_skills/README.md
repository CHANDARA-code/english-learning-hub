## 📊 Level-by-Level Comparison Matrix

| Level | CEFR Target | Exam Equivalent | Core Focus | Reading Speed |
| :--- | :--- | :--- | :--- | :--- |
| **B1** | Intermediate (មធ្យម) | Cambridge PET / IELTS 4.5–5.0 | Skimming for gist, scanning for facts, context clues | 140–180 wpm |
| **B2** | Upper Intermediate (មធ្យមកម្រិតខ្ពស់) | Cambridge FCE / IELTS 5.5–6.5 | Text architecture, advanced paraphrasing, TFNG, hedging | 200–240 wpm |
| **C1** | Advanced (កម្រិតខ្ពស់) | Cambridge CAE / IELTS 7.0–8.0 | Syntactic parsing, irony, unstated presuppositions, dialectics | 250–300 wpm |
| **C2** | Proficiency (កម្រិតជំនាញកំពូល) | Cambridge CPE / GRE Verbal 160+ | Epistemic synthesis, tertiary polysemy, gapped text, cadence | 300–380+ wpm |

## 🚀 How to Use These Modules

1. **Phase 1 — Study the Technique Guide (`technique/`):** Learn the cognitive mechanisms, scanning protocols, and distractor elimination tactics for your target level.
2. **Phase 2 — Analyze the Mock Exam Example (`examples/`):** Read the authentic ~300-word passage under timed conditions. Review the vocabulary breakdown (with Khmer translations) and observe how the exam questions test the text.
3. **Phase 3 — Complete the Practice Drills (`exercises/`):** Test your skills on both paragraph-level deconstruction and full-essay comprehension drills before checking the detailed answer explanations.
