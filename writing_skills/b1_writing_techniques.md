# 🟡 B1 Writing Techniques — Intermediate
## បច្ចេកទេសសរសេរ កម្រិត B1 (មធ្យម)

> **Goal at B1:** Write clear, connected text on familiar topics. Give simple opinions with reasons and examples.
> **Typical tasks:** Personal emails/letters, short stories, simple opinion paragraphs, short essays (120–180 words).

## 1. What B1 Writing Looks Like

| Area | B1 Target | ន័យខ្មែរ |
| :--- | :--- | :--- |
| Organisation | Clear beginning, middle, end | ការរៀបចំ: មានដើម កណ្តាល ចប់ |
| Linking | Basic connectors: *and, but, because, so, also, however* | ពាក្យតភ្ជាប់មូលដ្ឋាន |

## 2. The Paragraph: Topic Sentence → Support → Conclusion

A paragraph (កថាខណ្ឌ) is a group of sentences about **one** idea.

```
┌─────────────────────────────────────────┐
│ 1. TOPIC SENTENCE  – the main idea       │  ប្រយោគប្រធានបទ
│ 2. SUPPORTING SENTENCE – reason          │  ហេតុផល
│ 3. SUPPORTING SENTENCE – example         │  ឧទាហរណ៍
│ 4. SUPPORTING SENTENCE – more detail     │  ព័ត៌មានបន្ថែម
│ 5. CONCLUDING SENTENCE – repeat the idea │  ប្រយោគសន្និដ្ឋាន
└─────────────────────────────────────────┘
```

### Example
> **(1)** I think everyone should learn to cook. **(2)** First, cooking at home is cheaper than eating in restaurants. **(3)** For example, I spend about $3 on a home-cooked meal, but a restaurant meal costs $8 or more. **(4)** Also, home food is usually healthier because you choose the ingredients. **(5)** For these reasons, cooking is a useful skill for everyone.

### Tips
- ✅ The topic sentence should be **general**; the supporting sentences should be **specific**.
- ✅ Use the **PEE** method: **P**oint → **E**xplain → **E**xample.
- ❌ Do not put two different main ideas in one paragraph.

## 3. Linking Words (Connectors)

ពាក្យតភ្ជាប់ — they make your writing smooth and logical.

| Function | Connectors | Example |
| :--- | :--- | :--- |
| Adding (បន្ថែម) | *and, also, too, as well, in addition* | *In addition, it is good exercise.* |
| Contrast (ផ្ទុយ) | *but, however, although* | *It is cheap. However, it is slow.* |
| Reason (ហេតុផល) | *because, because of, since* | *I stayed home because it was raining.* |
| Result (លទ្ធផល) | *so, that's why, as a result* | *I was tired, so I went to bed early.* |
| Example (ឧទាហរណ៍) | *for example, for instance, such as* | *Sports such as football are popular.* |
| Order (លំដាប់) | *first, second, then, next, finally* | *First, open the box. Then, …* |
| Time (ពេលវេលា) | *when, while, after, before, as soon as* | *After I finished work, I went home.* |
| Conclusion (សន្និដ្ឋាន) | *in conclusion, to sum up, overall* | *In conclusion, …* |

### Punctuation with connectors
- **because / so / but / although** join two clauses in **one** sentence:
  *I like the city **because** it is lively.*
- **However / In addition / As a result** usually start a **new** sentence and take a comma:
  *The city is lively. **However,** it is very noisy.*

## 4. Sentence Building: Simple → Compound → Complex

Mix sentence types to avoid "robot writing".

| Type | Pattern | Example |
| :--- | :--- | :--- |
| Simple (ប្រយោគសាមញ្ញ) | one clause | *I live in Phnom Penh.* |
| Compound (ប្រយោគផ្សំ) | clause + *and/but/so* + clause | *I live in Phnom Penh, but I work in Kandal.* |
| Complex (ប្រយោគស្មុគស្មាញ) | main clause + *because/when/if/although/who/which* clause | *I live in Phnom Penh, which is the capital of Cambodia.* |

### Upgrade practice
- ❌ *I went to the market. I bought fruit. It was cheap.*
- ✅ *I went to the market **and** bought some fruit, **which** was very cheap.*

### Useful B1 structures
- **Relative clauses:** *The teacher **who** helped me was very kind.*
- **First conditional:** ***If** you study every day, you **will** improve quickly.*
- **Too / enough:** *The room was **too** small. / It wasn't big **enough**.*
- **Gerund as subject:** ***Reading** every day improves your vocabulary.*

## 5. Giving Opinions and Reasons

| Purpose | Phrases |
| :--- | :--- |
| Giving an opinion (ផ្តល់មតិ) | *I think… / In my opinion,… / I believe… / For me,…* |
| Agreeing (យល់ស្រប) | *I agree that… / I think this is true because…* |
| Disagreeing (មិនយល់ស្រប) | *I don't agree that… / I don't think that…* |
| Giving reasons | *The main reason is… / This is because…* |
| Other side | *Some people say… , but I think…* |

### Opinion formula
> **Opinion** + **because** + reason + **For example,** + example.
>
> *In my opinion, students should wear uniforms **because** they make everyone equal. **For example,** rich and poor students look the same at school.*

## 6. The 4-Paragraph Essay

B1 essays are usually **120–180 words**.

| Paragraph | What to write | Length |
| :--- | :--- | :--- |
| **1. Introduction** (សេចក្តីផ្តើម) | Introduce the topic + give your opinion | 2–3 sentences |
| **2. Body 1** (តួសេចក្តី ១) | First reason + example | 3–4 sentences |
| **3. Body 2** (តួសេចក្តី ២) | Second reason + example (or the other side) | 3–4 sentences |
| **4. Conclusion** (សេចក្តីសន្និដ្ឋាន) | Repeat your opinion in different words | 1–2 sentences |

### Useful phrases for each part
- **Introduction:** *Nowadays, many people… / These days, it is common to… / In this essay, I will explain why…*
- **Body:** *Firstly,… / Another reason is that… / On the other hand,…*
- **Conclusion:** *In conclusion,… / To sum up,… / For all these reasons, I believe…*

## 7. Emails and Letters (Informal & Semi-formal)

### Structure
1. **Greeting:** *Hi Dara, / Dear Mr. Smith,*
2. **Opening line:** *Thanks for your email. / I hope you are well.*
3. **Reason for writing:** *I'm writing to tell you about… / I'm writing to ask about…*
4. **Main content:** 1–2 short paragraphs
5. **Closing line:** *I hope to hear from you soon. / Write back soon!*
6. **Sign-off:** *Best wishes, / Love, / Kind regards,*

| Informal (friend) | Semi-formal (teacher, landlord) |
| :--- | :--- |
| *Hi Sophea,* | *Dear Ms. Lee,* |
| *Guess what!* | *I am writing to inform you that…* |
| *Can you…?* | *Could you please…?* |
| *See you soon!* | *I look forward to hearing from you.* |
| *Love, / Cheers,* | *Kind regards, / Best regards,* |
| Contractions OK: *I'm, don't* | Fewer contractions |

## 8. Writing a Short Story

- **Set the scene:** *It was a cold Saturday morning when…*
- **Use past tenses:** past simple for actions, past continuous for background.
  *I **was walking** home when I **saw** a small dog.*
- **Use time sequencers:** *At first, … Then, … Suddenly, … After that, … In the end, …*
- **Add feelings:** *I felt nervous / excited / relieved.*
- **End with a result or lesson:** *From that day, I always…*

## 9. Common B1 Mistakes

| ❌ Mistake | ✅ Correction | Rule |
| :--- | :--- | :--- |
| *Because it was raining.* (alone) | *I stayed home because it was raining.* | *Because*-clause needs a main clause |
| *I very like it.* | *I like it very much.* | Word order |
| *He don't like coffee.* | *He doesn't like coffee.* | Subject–verb agreement |
| *I am agree.* | *I agree.* | *Agree* is a verb |
| *Yesterday I go to school.* | *Yesterday I went to school.* | Past tense |
| *I went there, it was fun.* | *I went there. It was fun.* / *…, and it was fun.* | Comma splice (don't join with a comma) |
| *Informations, advices* | *information, advice* | Uncountable nouns |
| *Everybody have a phone.* | *Everybody has a phone.* | *Everybody* is singular |

## 10. B1 Self-Check List

- [ ] Does each paragraph have **one** clear main idea?
- [ ] Did I start each paragraph with a **topic sentence**?
- [ ] Did I give **reasons** and **examples**?
- [ ] Did I use at least **5 different linking words**?
- [ ] Did I use a mix of **simple, compound and complex** sentences?
- [ ] Are my **verb tenses** correct and consistent?
- [ ] Did I check **spelling, capital letters and full stops**?
- [ ] Did I stay within the **word count**?
